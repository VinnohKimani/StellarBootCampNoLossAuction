# Decentralized No Loss Auction Protocol (Stellar/Soroban)

A production-grade, decentralized **No-Loss Auction System** built on the Stellar network using the **Soroban Smart Contract Framework (v26)** and integrated seamlessly with a typed, responsive **Next.js 14 Frontend Engine**. 

This protocol guarantees an absolute zero capital loss environment for non-winning participants. Bidders are either immediately and automatically refunded via on-chain token routines when outbid, or their capital is held in a secure, audited programmatic escrow until manual claim criteria are achieved.
